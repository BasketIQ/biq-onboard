# Scoped staff continuations

The existing teams route accepts `staff_team`, `staff_action`, and `staff_target`. These are navigation inputs, never commands. The staff component resolves the requested team against its fresh directory, checks a targeted member or pending invitation exists, and highlights the native control. An unavailable team or record is an error; it does not fall back to another team. Transfer can preselect the proposed recipient; acceptance stays separate. All actual effects use the existing authenticated native endpoints and confirmations.

ES/EN browser scenarios cover explicit team selection, highlighted member permissions, no commands during navigation, and invalidated target with no editable directory. Staging evidence remains separate from local fixture tests.
